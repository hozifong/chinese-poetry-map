# 中国古诗地图 (Chinese Poetry Map)

一个交互式的地图应用，展示100首唐宋古诗所描绘的地点。

## 功能特性

- 🗺️ 中国地图展示
- 📍 标记唐宋古诗涉及的地点
- 🖱️ 鼠标悬停和点击交互
- 📖 点击显示古诗卡片
- 🎨 美观的视觉设计

## 项目结构

```
├── index.html          # 主文件
├── css/
│   └── style.css       # 样式文件
├── js/
│   ├── main.js         # 主逻辑
│   ├── map.js          # 地图绘制
│   └── data.js         # 古诗数据
├── data/
│   └── poems.json      # 古诗数据集
└── README.md
```

## 技术栈

- HTML5 + CSS3
- JavaScript (Vanilla)
- SVG / Canvas (地图绘制)
- GeoJSON (地理数据)

## 使用方法

1. 在浏览器中打开 `index.html`
2. 在地图上移动鼠标查看地点标记
3. 点击圆点查看对应的古诗卡片
